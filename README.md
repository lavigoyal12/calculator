# Simple Calculator

A responsive browser calculator built with HTML, CSS, and JavaScript. It supports addition, subtraction, multiplication, division, decimals, negative numbers, and keyboard input.

## Run locally

Open `index.html` in a web browser.

## Publish with GitHub Pages

1. Create a GitHub repository and upload `index.html`.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.
4. Once GitHub Pages finishes publishing, add the website URL to the LinkedIn project.
